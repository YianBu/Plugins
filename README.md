# YianBu 的 Dalamud 插件库

本仓库是 FFXIV Dalamud 第三方插件库的统一入口，使用 `pluginmaster.json` 维护全部插件清单。后续新增插件会加入同一清单，安装链接保持不变。

## 安装

在游戏内 卫月（Dalamud）→ 插件安装器 → 第三方仓库 中添加以下库链接，即可浏览并安装本库收录的全部插件：

```
https://raw.githubusercontent.com/YianBu/Plugins/main/pluginmaster.json
```
